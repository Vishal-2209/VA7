## Release Policy

- **Alpha (0.x)**: API may change between minor versions
- **Beta (1.0-beta)**: API freeze, testing period
- **Stable (1.0+)**: Semantic versioning, backward compatibility guaranteed

## Security Updates

Security patches are provided for the latest release only. Users are encouraged to stay on the latest version.
